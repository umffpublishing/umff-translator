# 표기 규칙 (Notation Rules)

## 영화 제목 표기
- 영화 제목은 꺾쇠 `< >`를 사용하고, 영문 제목은 이탤릭체로 쓴다. (예: <화양연화> / *In the Mood for Love*)
- 국영문 병기 시에는 꺾쇠만 사용한다. (예: <영원과 하루 Eternity and a Day>)
- 저작권자의 별도 제목표기 요청이 있을 경우 요청에 따라 표기한다.
- 제목·제작연도·감독을 함께 표기할 경우:
  - <화양연화>(왕가위, 2000) / In the Mood for Love(Wang Karwai, 2000)
  - <영원과 하루 Eternity and a Day>(테오 앙겔로풀로스 Theo Angelopoulos, 1998)
  - Eternity and a Day(Theo Angelopoulos 1998), In the Mood for Love(Wang Karwai, 2000)

## 작품 정보 표기
- 표기 순서: 제작국가, 제작연도, 러닝타임, 색채, 카테고리, 관람 등급. (책자의 경우 해당, 홈페이지는 자동)
- 예: `Korea | 2015 | 114min | Color | Documentary | G`

## 기타 영화 관련
- 제작연도는 마지막 최종 작업(제작)이 완료된 시점만 표기한다. (2002-2003 → X, 2003 → O)
- 러닝타임은 분·초 단위 모두 올림하여 분 단위로만 표기한다. 숫자 바로 뒤에 `min`, 마침표 없음. (예: 53min)
- 색채 표기: 컬러는 `Color`, 흑백은 `B&W`.
- 프리미어 표기: World Premiere / International Premiere / Asian Premiere / Korean Premiere 중 해당 사항 표기.

## 서적 표기
- 도서 제목은 겹낫표 『 』, 영문은 이탤릭, 저자명은 ( ) 안에 표기한다.
- 예: 『도전』 (크리스 보닝턴) / *Cahier du Cinema* (Chris Bonington)

## 기타 표기 (논문·정기간행물·TV·전시·음반·공연 등)
- 논문·정기간행물·TV 프로그램의 국문 제목은 낫표 「 」, 영문은 이탤릭, 저자명은 ( ).
- 전시는 《 》 사용, 국영문 동일. (예: 《모니카와 떠나는 세계명화 여행전》)
- 음반의 한글·영문 표기는 낫표 「 」 안에, 노래 제목은 작은따옴표 ‘ ’. (예: 「애비 로드」에 수록된 ‘Come Together’)
- **[한→영 번역 시]** 음반명은 「 」, 노래·곡 제목은 ‘ ’. 노래·곡 제목은 원문 언어 그대로 유지하고 번역하지 않는다. 큰따옴표 “ ” 사용 금지.
  - 예: 미니앨범 「The First Lumos」/ 싱글 ‘너에게로, 이별’, ‘For Sentimental Reasons’, ‘실연’
  - ✗ 잘못: “Heartbreak” (실연 번역 금지) / “For Sentimental Reasons” (큰따옴표 금지)
- 학교·단체·회사 명칭의 한글 표기는 띄어쓰기 없음. (예: 울주세계산악영화제조직위원회)
- 산악코스, 암벽등반루트 등 특정 지명을 표기한다.
- 공연: 국문은 작은따옴표 ‘ ’ (예: ‘양의 침묵’, ‘사적인 극장’) / 영문은 따옴표 없이 앞 글자만 대문자, 이탤릭 (예: *The Silence of the Sheep*, *Private Theatre*)

## 이름 표기

### 외국 인명 한글 표기 (영→한)
- **글로서리 등재 인명**: 학습 데이터 표기와 달라도 글로서리 표기를 절대 우선한다.
  - 예) 보이테크 쿠르티카 → Wojciech Kurtyka (Voytek 등 비공식 표기 사용 금지)
- **글로서리 미등재 인명: 원문 그대로 유지. 음역하지 않는다.**
  - 예) Benjamin Védrines → Benjamin Védrines (✗ 벤자맹 베드린으로 음역 금지)
- 글로서리 등재 인명 음역 기준: 원어 발음 기준, 현행 외래어 표기법 준수. 국내 관례 표기 우선.
  - 예) Wanda Rutkiewicz → 반다 루트키에비츠 / Reinhold Messner → 라인홀트 메스너

### 한국 인명 영문 로마자 (한→영)
- `성 + 공백 + 이름`, 이름 음절 사이 하이픈. 본인 영문명 있으면 우선.
  - 예) 이정진 → Jinna Lee / 배창호 → Bae Chang-ho / 엄홍길 → Um Hong-gil
- 한·중·일 한자식 이름: 성을 앞에 표기하고 성은 대문자로. 영문식 이름: 성을 뒤에 표기.
- 한국·중국 이름은 성과 이름을 붙여서 명기한다. 작품 속 캐릭터 이름도 동일.
- 본문 텍스트에서는 성과 이름의 첫 글자만 대문자로 표기한다.
- 별명·애칭은 첫 번째 언급 시 작은따옴표 `’ ‘` 안에 표기하고, 이후에는 부호 없음.
  (예: Francisco Marín ‘Novato’)

### 산 이름·지명
- proper-nouns.csv(TM·시트) 우선, 없으면 외래어 표기법.
  - 예) Denali → 드날리 / Chamonix → 샤모니 / Patagonia → 파타고니아

## 일반 콘텐츠 (문장부호) — 국영문 동일
- 대화 문구, 인용 구문은 큰따옴표 “ ” 를 사용한다.
- 인용구를 문장 그대로 사용하지 않을 경우 작은따옴표 ‘ ’ 를 사용한다.
- 말줄임표는 아래 점 3개만 사용한다.
- 콜론(:), 세미콜론(;)은 앞 글자와 붙여 쓰고 뒤에 오는 글자와는 한 칸 띄운다.
## 날짜 / 시간 / 통화 표기
- 날짜·시간: 9. 26.(금) 19:00 / Sep. 26(Fri) 19:00
- 기간: Sep. 26(Fri) - 30(Tue) 09:00 - 20:00
- 24시간 4자리 표기(04:00 / 16:00). AM/PM 불가. 시간 범위는 `-` 앞뒤로 한 칸씩 띄움.
- n번째·n주년: 표지에서 th 윗첨자, 본문에서는 윗첨자 X. (월 약어는 proper-nouns.csv ‘월’ 항목 참조)
- 통화: 15,000원 → 15,000 KRW

## 회사 표기
- 회사 공식 표기를 따른다: Co. / Inc. / Ltd. / Co.,Ltd.

| oxygen-free / without oxygen | 무산소 | 산소 없이 |
| speed ascent / speed climbing | 속도 등반 | — |
| summit push | 정상 공략 | — |
| alpine style | 알파인 스타일 | — |
| fixed rope | 고정 로프 | — |
| base camp | 베이스캠프 | — |
| technical climbing | 기술 등반 | — |
