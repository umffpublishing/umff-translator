## 0. 공통 원칙 (모든 방향·유형에 적용)

**규칙 0-1 강도(intensity) 보존**
원문의 강한 표현·어조를 임의로 순화하지 않는다. 강한 동사는 그 강도 그대로 옮기고, 완곡한 표현으로 대체하지 않는다.
```
✗ 잘못: 부서진다 → "무너질 듯"   (순화·불확실화)
✓ 올바름: 부서진다 → shatters / breaks apart / is destroyed

✗ 잘못: collapses → "흔들린다"   (강도 축소)
✓ 올바름: collapses → 무너진다
```

**규칙 0-2 수식어 완전 보존**
원문의 형용사·부사 수식어는 문법적으로 불가능하지 않은 한 모두 옮긴다. "자연스럽게 생략"하지 않는다.
```
✗ 잘못: painful struggle → "투쟁"           (수식어 누락)
✓ 올바름: painful struggle → 고통스러운 투쟁

✗ 잘못: brutally cold → "추운"              (부사 누락)
✓ 올바름: brutally cold → 살을 에는 듯 추운 / 혹독하게 차가운
```

**규칙 0-3 동어반복 해소 (영→한)**
영어에서 의미가 겹치는 수식어를 쌓을 때, 한국어에서는 하나로 합치거나 동사로 풀어 동어반복을 피한다.
```
✗ 잘못: liberating freedom → "해방적인 자유"   (동어반복)
✓ 올바름: liberating freedom → 해방 / 진정한 자유
✗ 잘못: painful agony → "고통스러운 고통"
✓ 올바름: painful agony → 극심한 고통 / 고통 속에서
```

## 1. 영→한

### 1-1. 시놉시스

**규칙 1** 관계절·분사구 → 앞당긴 관형절
```
EN: Emin, in his twilight years, toils alongside his faithful horse.
KO: 황혼기에 접어든 에민은 충실한 말과 함께 묵묵히 삶을 이어간다.

EN: The director, herself a climber, sets off to the Himalayas in her footsteps.
KO: 등반가인 감독은 그녀의 발자취를 따라 히말라야로 향한다.
```

**규칙 2** 영어 단문 나열 → `~고`, `~며`, `~지만`, `~는데`, `~면서`로 연결 (흐름이 자연스러울 때만)
```
EN: Eventually, Hangma leaves Namsang... She elopes with another man... but eventually returns...
KO: 결국 항마는 남상을 떠나 부모님의 집으로 돌아가고, 다른 남자 로이딥 슈레스타를 만나 떠나지만,
    가족이 배상금을 지불하지 못하자 결국 남상에게 돌아오게 되는데...
```
말줄임표: **아래 점 3개(`...`)만** 사용 (중간점 `···`·유니코드 `…` 불가).

**규칙 3** 영어 시제 무관하게 한국어 **현재형** 유지
```
EN: "Rupa and Maya (11) are best friends..."
KO: "11살 루파와 마야는 … 가장 친한 친구다."
```

**규칙 4** 외국 인명 첫 등장: 한글(영문) 병기, 이후 한글만
```
EN: "Namsang (Dayahang Rai) and his wife Hangma (Miruna Magar)"
KO: "남상(다야항 라이)과 그의 아내 항마(미루나 마가르)"
```

---

### 1-2. 프로그램 노트

**규칙 5** 감독 노트(1인칭) → 한국어도 1인칭 유지 (주어 반복 불필요)
```
EN: "I hope the film will be an unshakeable, unforgettable experience for the audience."
KO: "이 영화가 관객에게 흔들림 없고 잊히지 않는 경험으로 남기를 바란다."
```

**규칙 6** 3인칭 노트 — "This film" 등 반복 주어 첫 문장 이후 생략
```
EN: "This film documents... It is a touching and humane portrait..."
KO: "핀란드 라플란드의 마지막 전통식 금 채굴자들을 기록한 이 영화는… 감동적이고 인간적으로 담아냈다."
```

**규칙 7** 노트 마지막 문장 → 명사형(`~한 영화.`, `~이 돋보이는 애니메이션.`) 허용 (강제 아님)
```
EN: "The film's dynamic and immersive camerawork generates a thrilling sense of velocity..."
KO: "역동적이고 몰입감 있는 카메라 무빙이 만들어내는 짜릿한 속도감이 가히 환상적인 영화."
```

**규칙 8** 따옴표 〔v2 수정〕
> 직접 인용·대사 → 큰따옴표 `" "` 유지. 의역 인용·강조어 → 작은따옴표 `' '`.
> "영어 큰따옴표는 무조건 작은따옴표로 변환"은 **틀림**.
```
EN: The story reveals the "cheap" and "expendable" lives...  → KO: '싸구려'에 '소모품'이 되어버린...
EN: "I will climb it no matter what," he said.              → KO: "무슨 일이 있어도 오르겠다"고 그는 말했다.
```

### 1-3. 바이오

**규칙 9** 이름 생략, 국적+직함으로 시작
```
EN: "Robin Petré is a Danish film director and artist. In her work, she explores..."
KO: "덴마크 출신의 영화감독이자 예술가로 작품을 통해..."

EN: "Valentin Rapp is a filmmaker and photographer based in the Alps..."
KO: "알프스를 기반으로 활동하는 아웃도어 전문 영화감독 겸 사진작가."
```
패턴: `[국가] 출신의 [직함]` / `[국가] 기반의 [직함]` / `[직함] 겸 [직함]`

**규칙 10** 현재완료·과거형 → 한국어 현재형
```
EN: "He has produced over a hundred works..."
KO: "전 세계 기관과 방송사, 원정대, 다큐멘터리 작품을 100편 이상 제작해왔다."
```

**규칙 11** 작품명: 국문 꺾쇠 `〈 〉`, 영문 이탤릭 〔v2 수정〕
> 표기 시트 [4][5] 기준. 국·영문 병기 시 꺾쇠 하나 안에 함께: `〈한글제목 English Title〉`.
```
KO: "데뷔작 <그리고 저녁이 온다>는 풀프레임다큐멘터리영화제에서..."
EN: "Her debut, *Then Comes the Evening*, won at Full Frame Documentary Festival..."
병기: <영원과 하루 Eternity and a Day>
제목+감독+연도: <화양연화>(왕가위, 2000) / In the Mood for Love(Wang Karwai, 2000)
```

## 2. 한→영

### 2-1. 시놉시스

**규칙 12** 시간·장소 맥락 → 문두 부사구로 명시
```
KO: "6.25 전쟁으로 부모를 잃은 수지와 오목은..."
EN: "During the Korean War, Su-ji and Oh-mok lose their parents..."
```

**규칙 13** 시간 전환 → 전환사 명시 (`Years later`, `Meanwhile`, `Eventually`, `After`, `Only then`)
```
KO: "세월이 흐른 뒤 상류층이 된 수지는..."   → EN: "Years later, having risen to the upper class, she..."
KO: "수지는 비로소 진실을 깨닫는다."         → EN: "Only then does Su-ji finally come to terms with the truth."
```

**규칙 14** 한국어 관형절 → 영어 관계절(`who/which/that`) 또는 분사구문
```
KO: "고아원 출신 일환과 결혼한 오목은..."
EN: "Oh-mok, who marries Il-hwan, an orphan, ..."
```

**규칙 15** 한국어 현재형 → 영어 현재 시제(historical present) 유지
```
KO: "봉수는 가난한 농부로 딸의 혼례도 미룬 채 살아간다."
EN: "Bong-su is a farmer who has postponed his daughter's wedding due to poverty."
```

**규칙 16** 한국 고유 표현
- 음차 유지: `막걸리 → makgeolli`, `달밧 → dal bhat`
- 풀어서 설명: `6.25 전쟁 → the Korean War`, `외가 → maternal relatives`, `성인식 → a coming-of-age ritual`

---

### 2-2. 프로그램 노트

**규칙 17** 3인칭 노트 → `"This film..."` / `"The film..."` 으로 시작
```
KO: "<걸 클라이머>는 에밀리 해링턴의 24시간 엘 캐피탄 등반을 따라가는 작품이다."
EN: "*Girl Climber* follows Emily Harrington's bold 24-hour ascent of El Capitan..."
```

**규칙 18** 1인칭 노트 → `나/우리 → I/we` 유지, 생략 주어도 명시
```
KO: "이런 부정적인 생각의 굴레에서 벗어나기 위해 다큐를 찍기 시작했다."
EN: "I started filming this documentary to escape the cycle of negative thoughts."
```

**규칙 19** 한국어 긴 복문 → 영어 2~3문장으로 분리
```
KO: "핀란드 라플란드의 … 이들의 이야기를 감동적이고 인간적으로 담아냈다. 정말 아이러니한 것은…"
EN: "This film documents… It is a touching and humane portrait… The great irony is that…"
```

### 2-3. 바이오

**규칙 20** 이름을 주어로 시작 (영→한 규칙 9와 반대)
```
KO: "1982년 <꼬방동네 사람들>로 데뷔해..."
EN: "Bae Chang-ho made his directorial debut with *People in the Slum* in 1982..."
```

**규칙 21** 한국어 완료 사실 → 영어 현재완료 (`"has won"`, `"has appeared"`)
```
KO: "데뷔작 <그리고 저녁이 온다>는 … 50여 개의 상을 받았다."
EN: "Her debut, *Then Comes the Evening*, won at Full Frame, earning OSCAR® qualification and 50+ awards."
```

**규칙 22** 한국 영화 제목 → 꺾쇠 없이 영문 번역 제목(이탤릭) 〔v2 수정〕
> 공식 영문 제목 있으면 그것을, 없으면 직역.
```
<꼬방동네 사람들> → *People in the Slum*
<고래사냥>        → *Whale Hunting*
```

### 2-4. 섹션 서문

**규칙 23** 섹션명 → 영문 큰따옴표
```
KO: '자연' 섹션에서는 …  →  EN: The "Nature" section presents …
```
도입 동사: `presents` / `features` / `is composed of`

**규칙 24** 성격 비슷한 작품 → 주제별 단락, 세미콜론·연결사(`while`, `also`, `in addition`) 허용

**규칙 25** 귀속 표시: `― 프로그래머 이름 → ― Jinna Lee, Programmer` / `― 트렌토영화제 로잔나 스테딜레 → ― Rosanna Stedile, Trento Film Festival`

**규칙 26** `*` 각주 포함 전문 번역. 기관명·영화제명은 글로서리 확정 표기 사용.

**규칙 27** 길이 제한 없음. 작품명·감독명·정보 누락 불가.

---

### 2-5. 페스티벌 프로그램

**규칙 28** 청유·권유 → 영어 명령형·청유형
```
KO: 영남알프스에서 활력을 되찾아 보세요.  →  EN: Recharge with activities everyone can enjoy in the Yeongnam Alps.
KO: UMFF가 어린이 여러분을 초대합니다.   →  EN: UMFF invites young audiences into a world of dreams and wonder!
```

**규칙 29** 불릿 구조 그대로 유지

| 국문 | 영문 |
|---|---|
| 준비물 | Items to Bring |
| 유의 사항 | Notes |
| 프로그램 | Program |

**규칙 30** 공연·행사 소개 — 아티스트 이름 생략 금지 (규칙 9와 다름)
```
KO: 인순이는 세대를 초월하는 폭발적인 가창력으로...
EN: Insooni is a beloved diva whose powerful vocals...
```

**규칙 31** 길이 제한 없음. 내용 누락 불가.

## 4. 고유명사 표기

#### 4-1. 외국 인명 한글 표기
원어 발음 기준, 현행 외래어 표기법 준수. 국내 관례 표기 우선(표기 시트 [38][39]).
```
Wanda Rutkiewicz → 반다 루트키에비츠 / Reinhold Messner → 라인홀트 메스너
```

#### 4-2. 한국 인명 영문 로마자
`성 + 공백 + 이름`, 이름 음절 사이 하이픈. 본인 영문명 있으면 우선(표기 시트 [47]).
```
이정진 → Jinna Lee  /  배창호 → Bae Chang-ho  /  엄홍길 → Um Hong-gil
```
한·중·일 한자식: 성 앞. 영문식: 성 뒤(표기 시트 [40][42][44]).

#### 4-3. 산 이름·지명
TM·시트 우선, 없으면 외래어표기법.
```
Denali → 드날리 / Chamonix → 샤모니 / Patagonia → 파타고니아
```

표기법 세칙은 `notation-rules.md` 참조.
