## 0. 공통 원칙 (모든 방향·유형에 적용)

**규칙 0-1 강도(intensity) 보존**
원문의 강한 표현·어조를 임의로 순화하거나 과장하지 않는다. 강한 동사는 그 강도 그대로 옮기고, 완곡 표현으로 축소하거나 극적 표현으로 격상하지 않는다.
```
✗ 잘못(순화): 부서진다 → "무너질 듯"         ✓ 올바름: shatters / breaks apart
✗ 잘못(순화): collapses → "흔들린다"          ✓ 올바름: 무너진다

✗ 잘못(과잉): 도전 → struggle                ✓ 올바름: challenge / pursuit
✗ 잘못(의미 왜곡): 좌절 → defeat             (defeat = 패배; 다른 단어)
✗ 잘못(과잉):     좌절 → despair             (despair = 절망; 강도 초과)
✓ 올바름: frustration / setback / disappointment
✗ 잘못(과잉): 잊힌 → erased                  ✓ 올바름: forgotten  ← 원문에 없는 강한 단어 대체 금지
✗ 잘못(추가): 원문에 없는 수식어·단어 삽입 금지
              예) 제2차 세계대전 → "the devastation of WWII"  (devastation 추가 금지)
              예) 깃발로 기록됨 → "triumphs of"              (triumphs 추가 금지)
              예) 강한 바람 → "biting wind"                  (biting 추가 금지 → strong wind)
```

**규칙 0-2 수식어·절 완전 보존**
원문의 형용사·부사 수식어뿐 아니라 동기·이유·목적을 나타내는 구·절도 임의로 생략하지 않는다.
```
✗ 잘못: painful struggle → "투쟁"                            (수식어 누락)
✓ 올바름: painful struggle → 고통스러운 투쟁

✗ 잘못: brutally cold → "추운"                               (부사 누락)
✓ 올바름: brutally cold → 살을 에는 듯 추운 / 혹독하게 차가운

✗ 잘못: "진짜 삶을 찾아 네팔에 거주하면서" → "relocated to Nepal"   (동기 절 누락)
✓ 올바름: "in search of a life truly lived, relocated to Nepal"
```

**규칙 0-3 동어반복 해소 (영→한)**
영어에서 의미가 겹치는 수식어를 쌓을 때, 한국어에서는 하나로 합치거나 동사로 풀어 동어반복을 피한다.
```
✗ 잘못: liberating freedom → "해방적인 자유"   (동어반복)
✓ 올바름: liberating freedom → 해방 / 진정한 자유
✗ 잘못: painful agony → "고통스러운 고통"
✓ 올바름: painful agony → 극심한 고통 / 고통 속에서
```

**규칙 0-4 원문 내용 완전 보존 — 어떤 정보도 누락 금지**
원문의 모든 정보 단위를 빠짐없이 번역문에 반영한다. 두 가지 자주 빠지는 패턴:

**a) 작품 제목이 원문의 주어일 때** (`X follows / X tells / X documents` 등) 한국어 구조를 바꾸더라도 제목 포함.
```
✓ 〈K2 – Chasing Shadows〉는 … Benjamin Védrines가 … 여정을 따라간다.
✗ 알피니스트 벤자맹 베드린은 …  (제목 누락)

✓ 『Alpine Rising』은 한 세기 동안 … 이름들을 불러낸다.
✗ 한 세기 동안 … 이름들을 불러내는 책이다.  (제목 누락)
```

**b) 시간·정도·초점 한정어** (`yet / still / last / only / already / ever / often` 등) 누락 금지.
```
✗ his most ambitious challenge yet → "가장 야심 찬 도전"     (yet = 지금껏 누락)
✓                                 → 지금껏 가장 야심 찬 도전

✗ the last traditional gold miners → "전통식 금 채굴자들"    (last 누락)
✓                                 → 마지막 전통식 금 채굴자들

✗ the quiet unease that often drives people to extremes → "사람을 극단으로 몰아가는 조용한 불안"  (often 누락)
✓                                                      → 때로 사람을 극단으로 내모는 조용한 불안
```

**규칙 0-5 번역체 회피 (영→한)**
직역 구조·수동태를 한국어 자연 문체로 바꾼다.

| 번역체 패턴 | 수정 방향 |
|---|---|
| `~에 의해 드러났다 / ~에 의해 만들어졌다` | 능동으로 재구성: `~가 꺼내 보이다 / ~가 드러나다` |
| `raw → 순수한` (의미 불일치 직역) | `날것의 / 원초적인` |
| `reckoning → 성찰` (강도 순화) | `자기 직면 / 내면의 청산` |
| 영어 단문 나열을 하나의 긴 복합문으로 묶기 | 원문 단문 구조 유지 또는 짧게 분리 |
| 영어 동격·관계절 이식 (`her mother, an activist, passes away`) | 앞에 관형절로 쌓지 않는다. 문장 분리 또는 주어 재구성 |
| `~에 관한 / ~에 대한` 전치사 직역 | `~의 문제로` / `~를 둘러싼` / 서술어로 풀기 |
| `brings X → X를 가져다준다` / `faces X → X와 마주한다` | `찾아오다` / `맞닥뜨리다` / `넘어야 한다` 등으로 재구성 |
| `inspire X to Y → X에게 영감을 불어넣어 Y하다` | `뜻을 모으다 / 의기투합하다 / 이끌다` 등으로 재구성 |
| `lessons (must) call upon → 교훈을 되새겨야 한다` | `가르침을 마음에 새기다 / 다시 떠올리다` |
```
✗ 잘못: 예상치 못한 정직함과 명료함으로 Benjamin 자신에 의해 드러났다.
✓ 올바름: Benjamin 스스로가 예상치 못한 솔직함과 명료함으로 꺼내 보이면서.

✗ 잘못: raw physical achievement → 순수한 신체적 성취
✓ 올바름: raw physical achievement → 날것의 신체 성취

✗ 잘못: 환경 운동가이자 사진기자였던 어머니가 세상을 떠난 후 새 동네로 이사한다.
        (← "after her mother, an activist, passes away" 동격절 이식)
✓ 올바름: 어머니를 잃은 알마는 아버지와 함께 새 동네로 이사한다.

✗ 잘못: 연대와 용서에 관한 갈등으로 번져간다
✓ 올바름: 연대와 용서의 문제로 번져간다

✗ 잘못: 그토록 오래 기다려온 자유를 가져다줄 것인가 / 더 많은 시련과 마주해야 한다
✓ 올바름: 그토록 기다려온 자유가 찾아올 것인가 / 더 많은 시련을 넘어야 한다

✗ 잘못: 마을 사람들에게 영감을 불어넣어 자체적인 스키 대회를 만들어낸다
✓ 올바름: 마을 사람들과 뜻을 모아 자체적인 스키 대회를 만든다

✗ 잘못: 그들은 그 교훈을 다시 한번 되새겨야 한다
✓ 올바름: 그들은 그 가르침을 다시 마음에 새겨야 한다
```

**규칙 0-6 의역 허용 범위 — 페스티벌 이벤트 제외**
시놉시스·프로그램 노트·바이오·섹션 서문·도서 패널에서는 원문의 의미와 강도를 유지하는 범위 내에서 문학적 어휘 선택과 문장 단위 재구성을 허용한다.
페스티벌 이벤트(→ 섹션 2-5, 규칙 28~31)는 정보 전달이 목적이므로 직역 원칙을 유지한다.

허용:
- 원문 뉘앙스를 살리는 창의적 동사·어휘 선택
  ```
  ponder → 곱씹다   (더 생생한 표현)
  whose deaths weigh → 무겁게 쌓이는 죽음   (함축된 뉘앙스를 동사로 구현)
  precarious → 낡은   (맥락에 맞는 해석적 선택)
  ```
- 한국어 리듬을 위한 문장 단위 재구성·어순 변경
- 강조·호흡을 위한 파편 문장 사용
  ```
  "They are a group of shepherd siblings, aged eight to twenty."
  → 여덟 살부터 스무 살까지, 목동 형제자매들의 무리다.
  ```

금지 (의역 허용 범위에서도 적용):
- 원문에 없는 이미지·개념 추가 (→ 규칙 0-1 유지)
- 정보 누락 (→ 규칙 0-4 유지)
- 강도 왜곡·극적 격상 (→ 규칙 0-1 유지)

## 1. 영→한

### 1-1. 시놉시스

**규칙 1** 관계절·분사구 → 앞당긴 관형절
```
EN: Emin, in his twilight years, toils alongside his faithful horse.
KO: 황혼기에 접어든 에민은 충실한 말과 함께 묵묵히 삶을 이어간다.

EN: The director, herself a climber, sets off to the Himalayas in her footsteps.
KO: 등반가인 감독은 그녀의 발자취를 따라 히말라야로 향한다.
```

**규칙 2** 영어 단문 나열 → `~고`, `~며`, `~지만`, `~는데`, `~면서`로 연결 (흐름이 자연스러울 때만, 2~3개까지만; 4개 이상을 한 문장으로 묶지 않는다)
```
EN: Eventually, Hangma leaves Namsang... She elopes with another man... but eventually returns...
KO: 결국 항마는 남상을 떠나 부모님의 집으로 돌아가고, 다른 남자 로이딥 슈레스타를 만나 떠나지만,
    가족이 배상금을 지불하지 못하자 결국 남상에게 돌아오게 되는데...
```
말줄임표: **아래 점 3개(`...`)만** 사용 (중간점 `···`·유니코드 `…` 불가).

**규칙 3** 영어 시제 무관하게 한국어 **현재형** 유지
```
EN: "Rupa and Maya (11) are best friends..."
KO: "11살 루파와 마야는 … 가장 친한 친구다."
```

**규칙 4** 한국 인물(캐릭터명) + 배우 실명: 한글 캐릭터명(배우 실명) 병기
이 규칙은 **한국 배역명 + 외국 배우 실명** 패턴에만 적용한다. 서양 인명 음역에 적용하지 않는다(→ notation-rules.md 이름 표기).
```
EN: "Namsang (Dayahang Rai) and his wife Hangma (Miruna Magar)"
KO: "남상(다야항 라이)과 그의 아내 항마(미루나 마가르)"
```

**규칙 4-1** 영어 콜론(`:`) 구조 → 한국어 두 문장 분리
콜론이 긴 동격·설명절을 이끄는 경우, 콜론 앞을 첫 문장으로 끊고 콜론 이하를 별도 문장으로 처리한다. 수식절을 겹쳐 쌓지 않는다.
```
EN: he sets his sights on his most ambitious challenge yet: a fast, oxygen-free climb of K2
✓ 올바름: 지금껏 가장 야심 찬 도전에 나선다. K2를 무산소로, 빠르게 오르는 것이다.
✗ 잘못:   K2를 산소 없이 빠르게 오르는, 가장 야심 찬 도전에 나서는 여정을 따라간다.
          (수식절 이중 적층)
```
등산 전문 용어(무산소·베이스캠프 등) → notation-rules.md 등산·산악 전문 용어 참조.

### 1-2. 프로그램 노트

**규칙 5** 감독 노트(1인칭) → 한국어도 1인칭 유지 (주어 반복 불필요)
```
EN: "I hope the film will be an unshakeable, unforgettable experience for the audience."
KO: "이 영화가 관객에게 흔들림 없고 잊히지 않는 경험으로 남기를 바란다."
```

**규칙 6** 3인칭 노트 — "This film" 등 반복 주어 첫 문장 이후 생략
```
EN: "This film documents... It is a touching and humane portrait..."
KO: "핀란드 라플란드의 마지막 전통식 금 채굴자들을 기록한 이 영화는… 감동적이고 인간적으로 담아냈다."
```

**규칙 7** 노트 마지막 문장 → 명사형(`~한 영화.`, `~이 돋보이는 애니메이션.`) 허용 (강제 아님)
```
EN: "The film's dynamic and immersive camerawork generates a thrilling sense of velocity..."
KO: "역동적이고 몰입감 있는 카메라 무빙이 만들어내는 짜릿한 속도감이 가히 환상적인 영화."
```

**규칙 8** 따옴표 〔v2 수정〕
> - 직접 인용·대사 → 큰따옴표 `" "`
> - 의역 인용·강조어·**비유 표현** → 작은따옴표 `' '`
> - 방향 무관 일관 적용. 국문 작은따옴표 → 영문도 작은따옴표.
> - "영어 큰따옴표는 무조건 작은따옴표로 변환"은 **틀림**.
```
EN: The story reveals the "cheap" and "expendable" lives...  → KO: '싸구려'에 '소모품'이 되어버린...
EN: "I will climb it no matter what," he said.              → KO: "무슨 일이 있어도 오르겠다"고 그는 말했다.

KO: 낙엽을 '폴란드 망명정부의 지폐'라고 비유하던   (비유 → 작은따옴표)
EN: fallen leaves were likened to 'banknotes of the Polish government-in-exile'  ✓
EN: fallen leaves were likened to "banknotes of..."  ✗  (직접 인용 아님)

KO: 알피니즘을 '영혼의 해방'이자 '고도의 예술'로   (강조 → 작은따옴표)
EN: elevated alpinism into 'liberation of the soul' and 'a supreme art'  ✓
```

### 1-3. 바이오

**규칙 9** 이름 생략, 국적+직함으로 시작
```
EN: "Robin Petré is a Danish film director and artist. In her work, she explores..."
KO: "덴마크 출신의 영화감독이자 예술가로 작품을 통해..."

EN: "Valentin Rapp is a filmmaker and photographer based in the Alps..."
KO: "알프스를 기반으로 활동하는 아웃도어 전문 영화감독 겸 사진작가."
```
패턴: `[국가] 출신의 [직함]` / `[국가] 기반의 [직함]` / `[직함] 겸 [직함]`

**규칙 10** 현재완료·과거형 → 한국어 현재형
```
EN: "He has produced over a hundred works..."
KO: "전 세계 기관과 방송사, 원정대, 다큐멘터리 작품을 100편 이상 제작해왔다."
```

**규칙 11** 작품명: 국문 꺾쇠 `〈 〉`, 영문 이탤릭 〔v2 수정〕
> 표기 시트 [4][5] 기준. 국·영문 병기 시 꺾쇠 하나 안에 함께: `〈한글제목 English Title〉`.
```
KO: "데뷔작 <그리고 저녁이 온다>는 풀프레임다큐멘터리영화제에서..."
EN: "Her debut, *Then Comes the Evening*, won at Full Frame Documentary Festival..."
병기: <영원과 하루 Eternity and a Day>
제목+감독+연도: <화양연화>(왕가위, 2000) / In the Mood for Love(Wang Karwai, 2000)
```

## 2. 한→영

### 한→영 공통 원칙

**원문 충실도 우선**
원문에 없는 이미지·수식어·극적 어휘를 추가하지 않는다. 원문이 담백하면 번역도 담백하게. 문학적 윤색은 원문이 이미 그런 경우에만 따라간다.
```
✗ 경계       → "razor's edge"    ✓ → boundary / edge
✗ 잊힌       → "erased"          ✓ → forgotten
✗ 폴란드인들의 대자유 → "a great freedom uniquely their own"  ✓ → their great freedom
```

**어휘 등급(register)**
프로그램북 독자에게 맞는 자연스럽고 명확한 어휘를 선택한다. 라틴어 차용어 및 과도하게 격식적인 표현을 지양한다.

| 원문 | ✗ 피할 표현 | 이유 | ✓ 권장 |
|---|---|---|---|
| 역저(力著) / 역작 | magnum opus | 라틴어 차용어, 격식 과잉 | monumental work / significant work |
| 기록자 | chronicler | 역사 편찬가(편년사가) 뉘앙스 | record-keeper |
| 끈질긴 | tireless | '지칠 줄 모르는'으로 의미 어긋남 | persistent / relentless |
| 사료 | historical records | 너무 포괄적 | archival sources / archival research |

**숫자 표기**
본문 내 숫자는 문자로 풀어 쓴다. 연도·정밀 수치는 예외.
```
✗ 60여 년   → ✓ more than sixty years
✗ 2백만     → ✓ two million
예외: 1947년 → 1947 / 8,000m → 8,000 m / 97편 목록 등 정밀 수치
```

### 2-1. 시놉시스

**규칙 12** 시간·장소 맥락 → 문두 부사구로 명시
```
KO: "6.25 전쟁으로 부모를 잃은 수지와 오목은..."
EN: "During the Korean War, Su-ji and Oh-mok lose their parents..."
```

**규칙 13** 시간 전환 → 전환사 명시 (`Years later`, `Meanwhile`, `Eventually`, `After`, `Only then`)
```
KO: "세월이 흐른 뒤 상류층이 된 수지는..."   → EN: "Years later, having risen to the upper class, she..."
KO: "수지는 비로소 진실을 깨닫는다."         → EN: "Only then does Su-ji finally come to terms with the truth."
```

**규칙 14** 한국어 관형절 → 영어 관계절(`who/which/that`) 또는 분사구문
```
KO: "고아원 출신 일환과 결혼한 오목은..."
EN: "Oh-mok, who marries Il-hwan, an orphan, ..."
```

**규칙 15** 한국어 현재형 → 영어 현재 시제(historical present) 유지
```
KO: "봉수는 가난한 농부로 딸의 혼례도 미룬 채 살아간다."
EN: "Bong-su is a poor farmer who keeps putting off his daughter's wedding."
```

**규칙 16** 한국 고유 표현
- 음차 유지: `막걸리 → makgeolli`, `달밧 → dal bhat`
- 풀어서 설명: `6.25 전쟁 → the Korean War`, `외가 → maternal relatives`, `성인식 → a coming-of-age ritual`

### 2-2. 프로그램 노트

**규칙 17** 3인칭 노트 → 원문 주어에 맞는 표현으로 시작
- 주어가 **영화**인 경우: `"This film..."` / `"The film..."`
- 주어가 **도서·전시 패널** 등 비영화 텍스트인 경우: 제목 이탤릭으로 시작. **"This film" / "This book" 모두 금지. 문장 구조를 바꾸더라도 제목 유지.**
```
KO: "<걸 클라이머>는 에밀리 해링턴의 24시간 엘 캐피탄 등반을 따라가는 작품이다."
EN: "*Girl Climber* follows Emily Harrington's bold 24-hour ascent of El Capitan..."

KO: "『WINTER 8000』은 … 책으로 …"
EN: "*WINTER 8000* explores …"           ✓
EN: "This film explores …"               ✗  (도서를 film으로)
EN: "This book covers …"                 ✗  (제목 → This book 대체 금지)
```

**규칙 18** 1인칭 노트 → `나/우리 → I/we` 유지, 생략 주어도 명시. **필자의 1인칭 회상·논평도 동일 인칭 유지.**
```
KO: "이런 부정적인 생각의 굴레에서 벗어나기 위해 다큐를 찍기 시작했다."
EN: "I started filming this documentary to escape the cycle of negative thoughts."

KO: "한국의 산악계를 떠올리지 않을 수 없었다."  (필자 1인칭 회상)
EN: "I could not help but think of Korea's own mountaineering world."  ✓
EN: "one cannot help but think of..."  ✗  (비인칭 변환 금지)
```

**규칙 19** 한국어 긴 복문 → 영어 2~3문장으로 분리
```
KO: "핀란드 라플란드의 … 이들의 이야기를 감동적이고 인간적으로 담아냈다. 정말 아이러니한 것은…"
EN: "This film documents… It is a touching and humane portrait… The great irony is that…"
```

### 2-3. 바이오

**규칙 20** 이름을 주어로 시작 (영→한 규칙 9와 반대)
```

**규칙 22** 한국 영화 제목 → 꺾쇠 없이 영문 번역 제목(이탤릭) 〔v2 수정〕

```
<꼬방동네 사람들> → *People in the Slum*
<고래사냥>        → *Whale Hunting*

### 2-4. 섹션 서문

**규칙 23** 섹션명 → 영문 큰따옴표
```
KO: '자연' 섹션에서는 …  →  EN: The "Nature" section presents …
```
도입 동사: `presents` / `features` / `is composed of`

**규칙 24** 성격 비슷한 작품 → 주제별 단락, 세미콜론·연결사(`while`, `also`, `in addition`) 허용

**규칙 25** 귀속 표시: `― 프로그래머 이름 → ― Jinna Lee, Programmer` / `― 트렌토영화제 로잔나 스테딜레 → ― Rosanna Stedile, Trento Film Festival`

### 2-6. 도서·전시 패널

도서 소개 패널, 기관·단체 소개 패널, 사진·작품 설명 패널 등 전시 성격의 텍스트.

**규칙 34** 역사 사실·창립연도·인명·기관명 정확히 보존. 글로서리 확정 표기 우선.
